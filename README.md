# NurseMate (널스메이트) 🩺

간호학과 학부생(1~4학년) 및 병원 취업 준비생이 본인의 강의록 PDF와 자기소개서 초안을 입력하면 **국시형 5지선다 문제·의학용어 어원 및 약어 퀴즈·자소서 첨삭·부서별 모의면접**을 제공하는 생성형 AI 웹앱입니다.

---

## 1. 빠른 시작 방법

```bash
cd nursemate
npm install
npm run dev
```

브라우저에서 `http://localhost:3000` 으로 접속하면 바로 사용할 수 있습니다.

- **API 키 설정**: `.env.example`을 복사해 `.env.local`을 만든 뒤 `LLM_PROVIDER`(`gemini` | `openai` | `anthropic`), `LLM_MODEL`, `LLM_API_KEY`를 입력하면 해당 모델이 연동됩니다.
- `.env.local`이 없거나 API 키가 설정되지 않은 상태에서도 내장된 한국 간호학 스마트 데모 엔진이 작동하여 모든 기능을 즉시 체험·점검할 수 있습니다.

## 2. 화면 및 주요 기능

| 경로 | 화면 | 주요 내용 |
|---|---|---|
| `/` | 홈 | 학년별 맞춤 추천 기능 카드 (1~2학년: 용어 / 2~4학년: 문제 / 4학년: 취업) |
| `/study` | 강의록 문제 | PDF 업로드(페이지 번호 보존) → 소제목 요약 → 국시형 10문항 풀이(근거 `p.N` 표시) → `[다시 설명]` · `[요약노트(A4 인쇄)]` · `[일정표]` |
| `/terms` | 용어·약어 | 9종 기본 어원 분해 표 + 고정 정답(`data/abbreviations.json`) 기반 임상 약어 30문항 퀴즈 & 오답 재출제 |
| `/career/resume` | 자소서 첨삭 | 초안에 없는 사실·수치·자격 생성 금지 원칙 준수, 수정 전/후 비교, 직무역량 키워드, 보충 질문 목록 |
| `/career/interview` | 모의 면접 | 병원·희망부서·신분 설정 → 인성·직무·상황 대처 10문항 채팅 면접 + 100점 만점 총평, 면접 후기 TOP 5 & STAR 구조 분석 |
| `/my` | 내 기록 | 브라우저 `localStorage` 기반 강의록 오답노트, 약어 오답 기록, 모의 면접 점수 기록 |
