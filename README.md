# NurseMate (널스메이트) 🩺

간호학과 학부생(1~4학년) 및 병원 취업 준비생이 본인의 강의록 PDF와 자기소개서 초안을 입력하면 **국시형 5지선다 문제 · 의학용어 어원 및 약어 퀴즈 · 자소서 첨삭 · 부서별 모의면접**을 제공하는 생성형 AI 웹앱입니다.

---

## 💻 컴퓨터에 아무것도 설치되어 있지 않은 분을 위한 완벽 설치 & 실행 가이드

코딩 프로그램을 한 번도 설치해 본 적이 없는 컴퓨터(Windows / Mac)에서도 아래 **1단계 ~ 4단계**만 순서대로 따라 하시면 5분 안에 실행할 수 있습니다!

---

### 1단계. Node.js 설치하기 (최초 1회만)

이 웹앱을 실행하려면 **Node.js**라는 무료 프로그램 하나만 설치하면 됩니다.

1. 인터넷 브라우저(크롬, 사파리, 엣지 등)에서 **[https://nodejs.org/ko](https://nodejs.org/ko)** 에 접속합니다.
2. 화면 중앙의 초록색 버튼(**`Node.js 다운로드 (LTS)`**)을 클릭해 설치 파일을 내려받습니다.
   - **Windows**: 내려받은 `.msi` 파일을 더블클릭 → 계속 **`Next`** 버튼을 눌러 기본 설정 그대로 설치를 완료합니다.
   - **Mac (맥북)**: 내려받은 `.pkg` 파일을 더블클릭 → **`계속(Continue)`** 을 눌러 설치를 완료합니다.

---

### 2단계. NurseMate 프로젝트 파일 내려받기

Git이 설치되어 있지 않아도 **ZIP 파일**로 바로 내려받을 수 있습니다.

#### 방법 A. Git 없이 ZIP 파일로 간편하게 받기 (추천 ⭐)
1. 이 깃허브 페이지([https://github.com/kiwisoop/nursemate](https://github.com/kiwisoop/nursemate)) 우측 상단의 초록색 **`<> Code`** 버튼을 클릭합니다.
2. 메뉴 맨 아래의 **`Download ZIP`** 을 클릭합니다.
3. 내려받은 `nursemate-main.zip` 파일의 **압축을 풀어줍니다** (예: `바탕화면` 또는 `다운로드` 폴더).

#### 방법 B. Git이 설치되어 있는 경우
```bash
git clone https://github.com/kiwisoop/nursemate.git
```

---

### 3단계. 터미널(명령 프롬프트) 열기 및 폴더 이동

압축을 푼 `nursemate-main` (또는 `nursemate`) 폴더 안에서 명령창을 여는 방법입니다.

#### 🪟 Windows 사용자
1. 압축을 푼 **`nursemate-main` 폴더 안으로 들어갑니다** (`package.json` 파일이 보이는 곳).
2. 폴더 창 위쪽의 **주소 표시줄**을 마우스로 클릭한 뒤, **`cmd`** 라고 입력하고 **Enter(엔터)** 키를 누릅니다.
3. 검은색 명령 프롬프트 창이 바로 해당 폴더 위치에서 열립니다!
   > 💡 *(참고)* PowerShell에서 실행 시 보안 정책 오류가 뜬다면 꼭 위 방법대로 **`cmd`(명령 프롬프트)** 로 열어주세요.

#### 🍎 Mac (맥북) 사용자
1. 압축을 푼 **`nursemate-main` 폴더**를 마우스 우클릭(두 손가락 클릭)합니다.
2. 메뉴에서 **`폴더에서 새로운 터미널 열기`** (또는 `서비스` → `폴더에서 새로운 터미널 열기`)를 클릭합니다.
   - 만약 해당 메뉴가 안 보이면: `Cmd(⌘) + 스페이스바`를 눌러 **`터미널(Terminal)`** 을 검색해 실행한 뒤, 터미널 창에 `cd ` (cd 뒤에 띄어쓰기 한 칸!)를 입력하고 Finder에 있는 `nursemate-main` 폴더를 터미널 창 안으로 마우스로 끌어다 놓은(드래그 앤 드롭) 후 **Enter**를 누릅니다.

---

### 4단계. 패키지 설치 및 서버 실행하기

열린 검은색 창(터미널 또는 명령 프롬프트)에 아래 명령어를 **한 줄씩** 복사해서 붙여넣고 **Enter**를 누릅니다.

#### ① 필요한 부품(패키지) 자동 설치 (처음 한 번만 실행, 약 30초~1분 소요)
```bash
npm install
```

#### ② NurseMate 웹앱 서버 켜기
```bash
npm run dev
```

화면 아래쪽에 다음과 같은 글자가 나오면 성공입니다!
```text
▲ Next.js 15.1.6
- Local:   http://localhost:3000
✓ Ready
```

#### ③ 인터넷 브라우저로 접속하기
크롬이나 사파리 등 인터넷 창을 열고 주소창에 아래 주소를 입력해 접속하세요:
👉 **[http://localhost:3000](http://localhost:3000)**

> **종료하는 방법**: 사용을 마치고 서버를 끄고 싶을 때는 터미널 창에서 `Ctrl + C` 를 누르거나 터미널 창을 닫으시면 됩니다. 다음에 다시 켤 때는 `npm install` 없이 바로 **`npm run dev`** 만 입력하시면 됩니다.

## 🔑 (선택사항) 실제 AI API 키 연결하는 방법

API 키를 따로 설정하지 않아도 **내장된 한국 간호학 스마트 데모 엔진**이 자동으로 작동하여 모든 기능(PDF 문제 생성, 오답노트, 약어 30문항, 자소서 첨삭, 모의면접)을 바로 사용할 수 있습니다.

실제 Gemini / OpenAI / Claude 모델을 연결하고 싶다면:
1. 프로젝트 폴더 안에 있는 `.env.example` 파일을 복사해 이름을 **`.env.local`** 로 바꿉니다.
2. 메모장이나 텍스트 편집기로 `.env.local` 파일을 열고 본인의 API 키를 넣은 뒤 저장합니다.

```env
# 사용할 AI 제공자: gemini | openai | anthropic | mock
LLM_PROVIDER=gemini

# 사용할 모델명
LLM_MODEL=gemini-2.5-flash

# 발급받은 API 키 입력
LLM_API_KEY=여기에_발급받은_API_키를_붙여넣으세요
```
3. 터미널에서 서버를 껐다가(`Ctrl + C`) 다시 `npm run dev`로 켜면 적용됩니다.

## ❓ 자주 묻는 질문 (오류 해결)

1. **`'npm'은(는) 내부 또는 외부 명령, 실행할 수 있는 프로그램이 아닙니다` (`command not found: npm`) 라고 떠요!**
   - 1단계에서 Node.js를 설치하기 전에 열어둔 터미널 창에서는 인식되지 않습니다. **터미널(명령 프롬프트) 창을 완전히 닫았다가 다시 열고** 시도해 주세요.
2. **`npm ERR! enoent Could not read package.json` 오류가 떠요!**
   - 현재 터미널 위치가 `nursemate` 폴더 안이 아니라 바깥 폴더에 있는 경우입니다. 3단계 안내에 따라 `package.json` 파일이 들어 있는 폴더 안으로 이동한 뒤 다시 실행해 주세요.
3. **포트 3000번이 이미 사용 중이라고 나와요!**
   - 터미널에 표시되는 다른 주소(예: `http://localhost:3001`)로 접속하시면 똑같이 동작합니다.
